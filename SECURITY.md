# Security

The package reads text you give it and runs a fixed, embedded model over it.
It makes no network requests and writes no files.

If you find a way to make it crash, hang or use unreasonable memory on some
input, or any other security problem, please report it privately at
<https://github.com/bradvrudney/guesslang-go/security/advisories/new> rather
than in a public issue. You will get an answer as soon as the maintainer can
give one.

Only the latest release is supported.
